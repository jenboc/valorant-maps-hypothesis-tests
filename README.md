# VALORANT Map Hypothesis Testing

This is the companion repository for my [blog post about VALORANT map distribution](https://www.jensoncain.co.uk/posts/valorant-map-hypothesis-tests),
containing the R scripts used to carry out the hypothesis tests, as well as create
any visualisations included in the post.

The dataset can be found in `data/maps.csv` and the scripts in `scripts/`. Context
behind data collection and the purpose of the scripts can be found in the blog post itself.
